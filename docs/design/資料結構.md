# 資料結構
1. 電梯記錄
    + currentFloor: 當前樓層
    + direction: 行進方向。 -1 = 下樓, 0 = 停止, 1 = 上樓
    + openTime: 已開門的秒數。初始為 0
    + countForClose: 讀秒確認執行關門。初始為 0 ，應只有在使用者強制開門超過 5 秒後被參考/使用。
    + doorStatus: 0 = 已關門, 1 = 關門中, 9 = 開門中, 10 = 已開門
    + floorList: 所有樓層電梯按鈕的陣列，陣列值是第 2 點的樓層按鈕
        + 依序為 B2, B1, 1, 2, 3, 4, 5
2. 樓層按鈕
    + myFloor: 代表的樓層
    + isTarget: 是否被標記為目標樓層
3. 開門/關門按鈕
    + myAction: 代表的行為。 1 = 開門, 2 = 關門
