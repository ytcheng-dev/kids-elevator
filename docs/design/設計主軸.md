# 設計主軸

## App 目的
這是一款協助 2-5 歲小孩練習樓層數字認知的電梯情境 App，模擬情境為顧客進入電梯後看到的操作面板。App 分為兩種模式，分別對應學習與測驗兩個階段：
- **面板模式**：小孩可以自由點擊各樓層按鈕、搭配語音播報，反覆操作以熟悉、複習樓層數字
- **動物模式**：以語音出題的方式，讓小孩找出題目指定的樓層，測驗樓層數字的認知成果

## App 目標操作平台
Android

## 核心功能範圍
### 主選單
1. 作為 App 初始介面
2. 提供使用者選擇進入面板模式或動物模式
3. 提供設定是否開啟/關閉音效、語音的按鈕

### 面板模式
1. 使用者可以查看目前電梯停留的樓層
2. 使用者可以透過方向箭頭的滑動動畫得知目前電梯的移動狀況
3. 當使用者點擊目標樓層後，使用者可以從面板上看出哪些樓層已經被點擊
4. 使用者可以對已經被點擊的樓層，再次點擊進行取消
5. 使用者可以在電梯停留時，自行操作開門/關門
6. 在沒有被使用者操作的情況下，電梯會在目標樓層停留，並且每一樓層的開門時間為 5 秒鐘
7. 電梯移動中，使用者不可操作開門/關門
8. 當電梯開門中/已開門時，若使用者長按「開門」，則持續延長開門時間。當使用者放開「開門」時，若已開門時間未超過 5 秒，則持續等到 5 秒後再關門，若已開門時間已超過 5 秒，則再等 2 秒後關門
9. 當電梯關門中時，若使用者點擊「開門」，則可以再次開門
10. 當電梯到達目標樓層、開門、關門時，應提供語音播報功能
11. 預計每上/下一個樓層的時間為 2 秒鐘
12. 預計提供樓層包含：B2, B1, 1, 2, 3, 4, 5
13. 開門/關門動作的執行時間為 3 秒鐘
14. 關門完成後，等待 0.5 秒再開始移動至下一個目標樓層

### 動物模式
1. 語音播報題目，題目內容為希望前往哪個樓層
    + 語音的目標樓層是隨機決定，但必須與電梯當前樓層不同。
2. 使用者可以查看目前電梯停留的樓層
3. 使用者可以透過方向箭頭的滑動動畫得知目前電梯的移動狀況
4. 當使用者每次只能選擇一個樓層，電梯行進間不可點擊其他樓層，且樓層一旦選定即不可取消
5. 點擊「目前所在樓層」（電梯目前已停留的樓層）時，不會有任何反應——不會觸發移動、不會播放正確/錯誤動畫，也不會被視為答錯
6. 預計提供樓層包含：B2, B1, 1, 2, 3, 4, 5
7. 當到達使用者點擊的樓層時，若該樓層與語音播報題目的目標樓層相同，則播放一段「正確」的提示動畫，隨後出下一題（新題目的目標樓層同樣隨機決定）。若不同，則播放一段「錯誤」的動畫。
    + 正確動畫：使用者的角度是從電梯外面看到電梯門打開，並且會從電梯內走出一個動物(e.g. 小恐龍, 狗, 大象)，動物會有簡短的打招呼或跳舞的動畫，然後動物會離開畫面並且電梯關門。
    + 錯誤動畫：使用者的角度是從電梯外面看到電梯門打開，並且會從電梯內走出一個動物(e.g. 小恐龍, 狗, 大象)，動物會哭喪臉說明這不是自己想去的樓層，然後回到電梯內。
    + 每一道題目的小動物是隨機出現的
8. 播放動畫時，禁止操作樓層面板。
9. 僅提供直立模式
10. 使用者可重新播放語音

### 備註
1. 兩種模式的電梯狀態、面板狀態是完全獨立的
2. 主選單的音效、語音控制器是同時控制兩個模式的音效、語音狀態。

## 次要功能
### 主選單
1. 使用者可設定是否關閉音效／語音播報（開關預期由大人操作，不特別考慮小孩觸控精準度）
    + 拆成兩個各自獨立的開關：「按鈕提示音效」與「語音播報」，互不影響（例如可以只關閉按鈕音效、保留語音播報，或反之）

### 面板模式
1. 樓層按鈕排列依裝置方向自動調整
    + 直式（portrait）：樓層按鈕兩個一列
    + 橫式（landscape）：樓層按鈕改為 3/4 分兩列
    + 開門/關門按鈕獨立於樓層按鈕區塊之外

## UI 元件清單
### 主選單
1. 面板模式按鈕：提供進入面板模式
2. 動物模式按鈕：提供進入動物模式
3. 音效按鈕：開關音效
4. 語音按鈕：開關語音(含動畫聲音)

### 面板模式
1. 展示樓層的區域
    + 顯示目前樓層
    + 以方向箭頭的滑動動畫模擬電梯移動的過程
    + 當在目標樓層要開門/關門時，顯示開門/關門的提示動畫
2. 樓層按鈕
    + 包含樓層：B2, B1, 1, 2, 3, 4, 5
    + 當樓層被選擇時，需要有 highlight(或 focus )效果，當到達目標樓層後，取消 highlight。
    + 當按鈕已經被 highlight ，但在還沒有到達之前，樓層被再次點擊時，應取消 highlight ，代表取消前往該樓層
3. 開門/關門按鈕
    + 只有當電梯停在目標樓層的時候，才能有反應
    + 點擊時，觸發展示區域顯示開門/關門的提示動畫
4. 回到主選單的按鈕
    + 直式：放 AppBar
    + 橫式：放右上角

### 動物模式
1. 展示樓層的區域
    + 顯示目前樓層
    + 以方向箭頭的滑動動畫模擬電梯移動的過程
2. 樓層按鈕
    + 一列兩顆排列
    + 包含樓層：B2, B1, 1, 2, 3, 4, 5
    + 當樓層被選擇時，需要有 highlight(或 focus )效果，當到達目標樓層後，取消 highlight。
    + 樓層一旦選定，電梯行進間為不可取消狀態：不論點擊同一顆按鈕或其他按鈕，都不會有反應，需等到達目標樓層（播完對應動畫、面板解鎖）後才能再次操作
3. 回到主選單的按鈕
    + 直式：放 AppBar
4. 動畫顯示層
    + 用於顯示正確/錯誤動畫
5. 重播語音按鈕

## 明確不執行的事項
