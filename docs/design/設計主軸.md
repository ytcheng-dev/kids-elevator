# 設計主軸

## App 目的
這是一個模擬電梯操作面板的 App，目標是提供 2-5 歲的小孩體驗操作電梯的面板。模擬的情境為：顧客進入電梯之後可以看到的操作面板。

## App 目標操作平台
Android

## 核心功能範圍
### 主選單
1. 作為 App 初始介面
2. 提供使用者選擇進入面板模式或動物模式
    + 動物模式需提供選擇是否啟用語音互動模式
3. 提供設定是否開啟/關閉音效、語音的按鈕

### 面板模式
1. 使用者可以查看目前電梯停留的樓層
2. 使用者可以透過數字滾動的動畫得知目前電梯的移動狀況
3. 當使用者點擊目標樓層後，使用者可以從面板上看出哪些樓層已經被點擊
4. 使用者可以對已經被點擊的樓層，再次點擊進行取消
5. 使用者可以在電梯停留時，自行操作開門/關門
6. 在沒有被使用者操作的情況下，電梯會在目標樓層停留，並且每一樓層的開門時間為 5 秒鐘
7. 電梯移動中，使用者不可操作開門/關門
8. 當電梯開門中/已開門時，若使用者長按「開門」，則持續延長開門時間。當使用者放開「開門」時，若已開門時間未超過 5 秒，則持續等到 5 秒後再關門，若已開門時間已超過 5 秒，則再等 2 秒後關門
9. 當電梯關門中時，若使用者點擊「開門」，則可以再次開門
10. 當電梯到達目標樓層、開門、關門時，應提供語音播報功能
11. 預計每上/下一個樓層的時間為 2 秒鐘
12. 預計提供樓層包含：B2, B1, 1, 2, 3, 4, 5

### 動物模式
1. 使用者可以查看目前電梯停留的樓層
2. 使用者可以透過數字滾動的動畫得知目前電梯的移動狀況
3. 當使用者點擊目標樓層後，使用者可以從面板上看出哪些樓層已經被點擊
4. 當電梯到達目標樓層、開門、關門時，應提供語音播報功能
5. 預計提供樓層包含：B2, B1, 1, 2, 3, 4, 5
6. 播放動畫時，禁止操作樓層面板。

#### 關閉語音互動模式(預設)
1. 使用者可以對已經被點擊的樓層，再次點擊進行取消
2.  當電梯到達目標樓層時，顯示一個彈跳視窗，用於播放一個動畫畫面：使用者的角度是從電梯外面看到電梯門打開，並且會從電梯內走出一個動物(e.g. 小恐龍, 狗, 大象)，動物會有簡短的打招呼或跳舞的動畫，然後動物會離開畫面並且電梯關門。動畫完成後，關閉彈跳視窗。
3. 動畫中的小動物是隨機出現的

### 備註
1. 兩種模式的電梯狀態、面板狀態是完全獨立的
2. 主選單的音效、語音控制器是同時控制兩個模式的音效、語音狀態。

## 次要功能
### 主選單
1. 使用者可設定是否關閉音效／語音播報（開關預期由大人操作，不特別考慮小孩觸控精準度）
    + 拆成兩個各自獨立的開關：「按鈕提示音效」與「語音播報」，互不影響（例如可以只關閉按鈕音效、保留語音播報，或反之）

### 面板模式
1. 樓層按鈕排列依裝置方向自動調整
    + 直式（portrait）：樓層按鈕兩個一列
    + 橫式（landscape）：樓層按鈕改為 3/4 分兩列
    + 開門/關門按鈕獨立於樓層按鈕區塊之外

### 動物模式
1. 樓層按鈕排列依裝置方向自動調整
    + 直式（portrait）：樓層按鈕兩個一列
    + 橫式（landscape）：樓層按鈕改為 3/4 分兩列
    + 開門/關門按鈕獨立於樓層按鈕區塊之外
2. 語音互動模式
    + 開啟此模式時，使用者一次只能點擊一個樓層按鈕
    + 選定樓層後，不可取消目標樓層
    + 系統播放一段語音，語音內容會要求要前往的樓層。語音的目標樓層是隨機決定，但必須與電梯當前樓層不同。
    + 使用者的目標是前往語音要求的樓層
        + 當前往正確的樓層則播放成功的音效與動畫(即關閉互動時的動畫)，當前往了不正確的樓層則播放錯誤的音效與動畫(額外製作)
        + 當使用者前往不正確的樓層，關閉動畫之後，再次播放相同的語音
        + 當使用者前往正確的樓層，關閉動畫之後，播放另一個隨機樓層
    + 需提供可重新播放語音的功能
    

## UI 元件清單
### 主選單
1. 面板模式按鈕：提供進入面板模式
2. 動物模式按鈕：提供進入動物模式
3. 動物語音互動模式：提供決定進入動物模式時，是否啟用語音互動模式
4. 音效按鈕：開關音效
5. 語音按鈕：開關語音(含動畫聲音)

### 面板模式
1. 展示樓層的區域
    + 顯示目前樓層
    + 滾動數字已模擬電梯移動的過程
    + 當在目標樓層要開門/關門時，顯示開門/關門的提示動畫
2. 樓層按鈕
    + 包含樓層：B2, B1, 1, 2, 3, 4, 5
    + 當樓層被選擇時，需要有 highlight(或 focus )效果，當到達目標樓層後，取消 highlight。
    + 當按鈕已經被 highlight ，但在還沒有到達之前，樓層被再次點擊時，應取消 highlight ，代表取消前往該樓層
3. 開門/關門按鈕
    + 只有當電梯停在目標樓層的時候，才能有反應
    + 點擊時，觸發展示區域顯示開門/關門的提示動畫
4. 回到主選單的按鈕
    + 直式：放 AppBar
    + 橫式：放右上角

### 動物模式
1. 展示樓層的區域
    + 顯示目前樓層
    + 滾動數字已模擬電梯移動的過程
2. 樓層按鈕
    + 包含樓層：B2, B1, 1, 2, 3, 4, 5
    + 當樓層被選擇時，需要有 highlight(或 focus )效果，當到達目標樓層後，取消 highlight。
    + 當按鈕已經被 highlight ，但在還沒有到達之前，樓層被再次點擊時，應取消 highlight ，代表取消前往該樓層
3. 開門/關門按鈕
    + 僅裝飾，無實際作用
4. 回到主選單的按鈕
    + 直式：放 AppBar
    + 橫式：放右上角
5. 彈跳視窗
    + 用於顯示動畫
6. 重播語音按鈕
    + 只有在開啟語音互動模式時顯示
