## 三、`PanelPage` 裡還沒測到的流程

目前的測試集中在「點樓層 → 移動 → 抵達」。以下沒有測到：

- [ ] 點擊開門／關門按鈕（`doorButtonOnTap`），包含電梯移動中按下無反應、關門完成後 0.5 秒內（尚未出發）按開門可以開門
- [ ] 抵達後開門 → 等 5 秒 → 自動關門 → 等 0.5 秒 → 前往下一個目標
- [ ] 關門中按開門（點擊與長按）不會重新開門（`設計主軸.md` 面板模式第 9 點），門照常關完
- [ ] 長按開門的兩條分支（未滿 5 秒等到 5 秒／超過 5 秒再等 2 秒）：需要先把 `openedAt` 與 `elapsed` 的 `DateTime.now()` 改成 `clock.now()`（Phase 26 延後議題）
- [ ] 語音或音效關閉（`isAllow = false`）時，流程仍能正常走完（`VoicePlayer` 同步呼叫 `cb`）
- [ ] 橫式版面的互動（目前橫式只有 init 測試）
- [ ] `dispose()` 有呼叫 player 的 `dispose()` 與 `_timerManager.clear()`
- [ ] idle 時點目前樓層會取消標記（142～146 行）、移動中抵達後轉向（`switchDirectionOrIdle` 211～215 行）
