# 電梯面板模擬 App — Flutter 學習專案總覽

## 專案目的

透過完成一個「電梯面板模擬 App」，練習 Flutter 的常用語法、排版、結構、套件引用等基礎概念與技術。

**學習者背景**：熟悉 JavaScript / Node.js，未使用過 Flutter / Dart，未使用過 React。

**核心原則**：本專案重點是**學習與練習**，不是快速完成專案。講師角色（Claude）不會直接提供完整文件或完整程式碼，而是透過引導、範例、提示、引導式問句，協助學習者自行思考與實作。

---

## 對話與互動模式

- **每個新對話只討論一個 Phase**，避免內容混雜、失焦。
- 講師先講解該階段的核心概念，再提出引導式問題，由學習者先思考、先寫（不論是設計文件文字或程式碼）。
- 學習者提交想法/程式碼後，講師 review、指出問題、給提示或範例片段，非必要不給完整解答。
- 學習者有明確要求時，才提供較完整的範例。
- 每個 Phase 结束後，建議整理該階段的產出（文件段落、程式碼、學到的觀念），作為下一個 Phase 對話的背景。

---

## 學習路徑總覽

| Phase | 主題 | 核心觀念 | 與 JS/Node.js 經驗對照 |
|---|---|---|---|
| 0 | 需求釐清 + 設計文件 | 拆解需求、定義 UI 元件、資料結構 | 撰寫 spec / user story |
| 1 | 環境建置 + Dart 基礎 | 變數、型別、null safety、function、class | TypeScript 強型別、ES6 class |
| 2 | 第一個畫面（靜態 UI） | Widget 樹、`StatelessWidget`、`build()` | React Component、JSX |
| 3 | 電梯面板排版 | `Row` / `Column` / `Container` / `Expanded` / `Stack` | Flexbox（`display: flex`） |
| 4 | 互動與狀態 | `StatefulWidget`、`setState`、按鈕事件 | React `useState` |
| 5 | 電梯業務邏輯 | 資料模型（樓層、方向、門狀態）、狀態機思維 | 前端 state machine / reducer |
| 6 | 動畫效果 | `AnimatedContainer`、`AnimationController` | CSS transition / requestAnimationFrame |
| 7 | 元件化與專案結構 | 拆檔案、資料夾規劃、可重用 widget | 拆分 component 檔案 |
| 8 | 套件引用 | `pubspec.yaml`、加入第三方套件 | `npm install` |
| 9 | 進階狀態管理（選修） | `Provider` 或 `Riverpod` | Redux / Zustand / Context API |
| 10 | 收尾與延伸 | 多電梯、多樓層設定、程式碼打磨 | — |

> 此路徑可依實際學習狀況調整順序、合併或拆分階段，於各 Phase 對話中彈性討論。

---

## 使用方式提醒

1. 在 Project 中開啟新對話。
2. 貼上本文件（或摘要相關 Phase 段落）。
3. 註明「現在要進行 Phase X」。
4. 依講師引導逐步進行該階段的思考與練習。
5. 階段結束後保留產出，作為下一階段的銜接背景。
